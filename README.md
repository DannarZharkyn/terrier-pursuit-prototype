Terrier Pursuit

A web-based scavenger hunt platform developed for Boston University.

The application allows organizers to create and manage events, form teams, generate QR codes, and track participant progress.

Tech Stack: Next.js, React, TypeScript, Tailwind CSS, Supabase.
